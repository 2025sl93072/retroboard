# Contributing to RetroBoard

## Setup

```bash
git clone https://github.com/2025sl93072/retroboard.git
cd retroboard
pip install -r requirements.txt
python app.py
```

## Running Tests

```bash
pip install pytest
pytest tests/ -v
```

## Branching

- Create feature branches from `main`: `git checkout -b feature/your-feature`
- Open a Pull Request against `main` when ready
- Link the relevant issue in your PR description (e.g. `Closes #3`)

## Pull Request Guidelines

- Each PR should address one issue
- Include or update tests for new functionality
- Request a review from a teammate before merging

## Reporting Issues

Use [GitHub Issues](https://github.com/2025sl93072/retroboard/issues).
